Scientific boundary
The source page states that the visualization is made from ECCO2 model output and that the page does not store the underlying datasets. The site's current audio maps features sampled from the rendered video. It does not expose original model fields, calculate current speed, or report calibrated pixel-level temperature.

Numerical ECCO2 data status
Not downloaded or integrated. ECCO2's official product list identifies ECCO Cube92 as the legacy ECCO2 product. NASA/JPL ECCO Drive is recorded as a candidate data access point at https://ecco.jpl.nasa.gov/drive/files/ECCO2/. Any numerical files must be checked for variables, units, dates, grid, and access conditions before use.
